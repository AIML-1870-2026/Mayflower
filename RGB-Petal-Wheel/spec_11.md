# Chromalava — RGB Color Studio
## Project Specification

---

## Overview

Chromalava is an interactive RGB color tool built as a single standalone HTML file with no build step or dependencies beyond CDN-loaded React. It uses the visual metaphor of a lava lamp to make additive light mixing tangible — three glowing blobs (red, green, blue) float and merge inside a glass vessel, combining exactly as projected light does so that overlapping regions produce yellow, cyan, magenta, and white. Alongside the live animation, the tool includes a harmony-based palette generator, a WCAG contrast checker, a color blindness simulator, and an accessible palette auto-adjuster — all wrapped in a retro 1970s scientific-instrument aesthetic with dark amber backgrounds, gold borders, and Courier Prime monospace type throughout.

---

## Features

- Animated lava lamp vessel with three RGB blobs that float, morph, and mix using additive canvas blending
- Blob height, size, and glow intensity respond in real time to the R, G, and B channel values
- Three vertical faders (R, G, B) with drag interaction; value readout updates live
- Live hex and RGB readout with one-click copy buttons for both formats
- Manual hex input field — type any valid hex to set the sliders
- Click-to-pick color from the lava lamp — hover shows a tooltip with the pixel's hex, click sets the sliders to that color with a ripple animation confirmation
- Palette generator with five harmony types: complementary, analogous, triadic, split-complementary, tetradic
- Randomize button with spin animation; sync toggle to link or decouple the palette base from the explorer color
- Click-to-copy palette swatches with AA/AAA contrast badges and ratio displayed on each
- Color blindness simulation (protanopia, deuteranopia, tritanopia) applied via pixel-level Brettel matrix transforms directly on the canvas every animation frame
- Side-by-side lava lamp comparison view — filtered vessel on the left, original on the right — when CB simulation is active
- CB simulation also applied to palette swatches so designers see how the full palette reads under each condition
- WCAG contrast checker with live text preview and pass/fail badges for AA Normal, AA Large, AAA Normal, and UI Components
- Accessible palette mode — auto-adjusts each swatch's lightness until it meets a chosen minimum ratio against a chosen background; shows before/after with ADJUSTED/PASSED labels; resettable
- Additive mixing legend (R+G=Yellow, R+B=Magenta, G+B=Cyan, all=White)

## Layout

The page is a single scrolling column, max-width 1300px, centered, 40px side padding, divided into three numbered sections separated by gold rule dividers with spaced uppercase Courier Prime labels.

**Header** — "CHROMALAVA" in wide-spaced Palatino serif (gold, glowing text-shadow) with "RGB COLOR STUDIO" subtitle in small-caps Courier Prime. A 1px gold border separates it from the body.

**Section I — Animated Color Explorer** — a horizontal flex row. Left column: CB simulation selector strip (Off / Protanopia / Deuteranopia / Tritanopia pill buttons), then the lava lamp vessel (canvas with gold metallic end caps above and below). When CB simulation is active, two vessels appear side by side — filtered left, original right. Right column: three vertical faders, hex/RGB readout panel, hex text input, and additive mixing legend.

**Section II — Palette Generator** — harmony type pill buttons and randomize/sync controls across the top, then five palette swatches below in a horizontal flex row.

**Section III — Accessibility & Simulation Tools** — three toggle buttons (Contrast Checker, Color Blindness Simulator, Accessible Palette Mode). Clicking opens the corresponding panel below; clicking again closes it. Only one panel is open at a time.

**Footer** — single line of spaced monospace text.

## Explorer Details

**Visual metaphor:** The lava lamp is a vessel for additive light mixing. Each blob represents one channel — red, green, blue. They are drawn with `globalCompositeOperation: "lighter"` so their overlap behaves like real projected light. Blobs are rendered with three layered radial gradients: an outer glow, a core body, and a bright hot center, giving them a luminous, molten quality.

**Controls:** Three vertical drag faders labeled R, G, B. Dragging upward increases the channel value 0–255. The colored fill track and gold thumb update continuously as you drag. Each channel value directly drives that blob's size (radius scales with value), vertical position (higher value = blob rises), and intensity (brighter glow).

**Animation:** Each blob has its own sinusoidal drift path with independent phase offsets so they never move in lockstep. Shape is generated by perturbing a circular path with three overlapping sine waves at different frequencies and speeds, producing organic morphing. The loop runs via `requestAnimationFrame` at 60fps. The canvas is 290×390px.

**Color blindness on the explorer:** When a CB type is selected, blobs are first drawn to a hidden offscreen canvas with true RGB colors. Then `getImageData()` pulls every pixel, a 3×3 Brettel matrix is applied in JavaScript per-pixel, and `putImageData()` writes the transformed result to the visible canvas. This happens every frame and correctly handles the additive blending that CSS filters cannot. The original vessel renders simultaneously beside it for direct comparison.

**Click-to-pick:** On hover, the cursor reads the pixel under it from the offscreen (pre-CB) buffer and shows a floating tooltip with a color swatch and hex code. Click sets the RGB sliders to that color. A gold expanding ring ripple animates at the click point.

## Palette Generator Details

**Harmony types** (five, selectable via pill buttons):
- **Complementary** — base + opposite hue on the color wheel, with lightness variants
- **Analogous** — five hues spanning ±40° around the base
- **Triadic** — three hues 120° apart with lightness variants to fill out five swatches
- **Split-complementary** — base + two hues flanking the complement at ±30°
- **Tetradic** — four hues 90° apart plus a fifth midpoint variant

**Base color:** By default the palette base is synced to the explorer's current RGB mix. A sync toggle decouples them and reveals a separate hex input for an independent base color. The randomize button applies a random RGB to whichever source is active.

**Swatch display:** Five equal-width cards. Each shows the full color as a background fill, the hex code in Courier Prime at the bottom, and three small badge pills — AA pass/fail, AAA pass/fail, and the numeric contrast ratio. Contrast is calculated against the accessible mode background if one is set, otherwise against an automatically chosen dark or light value. Hovering lifts the swatch 5px with an enhanced glow shadow. Clicking copies the hex and briefly shows "COPIED!". When CB simulation is active, swatch colors are matrix-transformed so they preview how the palette reads to a color blind viewer.

## Interactions

- **Fader drag** — mousedown on the track or thumb begins drag; mousemove anywhere on the window updates the value; mouseup releases. Clamped 0–255. Blobs, readout, and palette all respond immediately.
- **Lava lamp hover** — tooltip shows current pixel's hex sampled from the pre-CB offscreen canvas; crosshair cursor on non-background pixels.
- **Lava lamp click** — sets R/G/B sliders to the sampled pixel color; gold ripple ring animates at click point.
- **Harmony type buttons** — switching type regenerates the palette immediately and clears any accessible mode adjustments.
- **Randomize** — generates random RGB, applies to explorer or palette base depending on sync state; button icon spins for 0.5s.
- **Sync toggle** — animated pill switch; OFF state reveals a separate base hex input for the palette.
- **Palette swatch click** — copies hex to clipboard; "COPIED!" overlay appears for 1.4 seconds.
- **Hex input** — validates on blur or Enter; valid input updates sliders; invalid reverts to current hex.
- **CB selector** — Off / Protanopia / Deuteranopia / Tritanopia buttons above the vessel; switching immediately re-transforms the canvas every frame and re-renders palette swatches.
- **Tool panel buttons** — clicking an inactive tool opens its panel; clicking the active tool closes it.
- **Contrast Checker** — hex text input + native color picker for each color; ratio and all four badges update live; text preview shows both orientations of the pair.
- **Accessible Palette — Auto-Adjust** — user picks a background color and minimum ratio (AA Large / AA / AAA); clicking the button lightness-nudges each swatch until it passes; results show old → new with ADJUSTED or PASSED label; Reset restores originals.

## Visual Style

**Colors:**
- Page background: deep near-black amber radial gradient — `#2a1a08` → `#130f04` → `#0c0804`
- Primary text: warm cream `#f5e6c8`
- Active gold (borders, buttons, readout): `#d4a017`
- Muted gold (labels, inactive states): `#b8860b` / `rgba(184,134,11,0.25–0.5)`
- CB mode accent: orange `#ff9500`
- Pass badges: `rgba(60,180,60,0.75)`
- Fail badges: `rgba(200,60,60,0.65)`
- Canvas fill: near-black `rgb(8,5,2)`

**Fonts:**
- Logotype: Palatino Linotype / Palatino serif, weight 400, letter-spacing 10px, uppercase, gold with warm glow shadow
- All UI — labels, values, badges, buttons, readouts: Courier Prime monospace (Google Fonts), 8–22px, uppercase, wide letter-spacing
- No other typefaces used

**Overall aesthetic:** Retro 1970s scientific instrument. Dark, warm, analog. An SVG fractal noise grain texture overlays the entire page at fixed position (opacity 0.6) to add film-like texture. All borders are 1px semi-transparent gold. Buttons are pill-shaped with very subtle fill. No sharp whites anywhere — everything is warm-tinted cream or amber. Box shadows glow in the current color. The lava lamp has gold metallic end caps made from CSS gradient divs above and below the canvas, with matching box-shadows. Custom scrollbar styled dark amber.

## Technical Notes

- **Single HTML file** — no build step, no bundler, runs by opening in a browser. React 18 and Babel standalone are loaded from cdnjs.cloudflare.com. Babel transpiles JSX at runtime via `<script type="text/babel">`.
- **React 18** — all functional components with hooks (`useState`, `useEffect`, `useRef`, `useCallback`). Animation never triggers React re-renders — all per-frame state is managed via `useRef`.
- **Canvas rendering** — `requestAnimationFrame` loop inside a `useEffect`. Two canvases per BlobCanvas instance: one offscreen (always pure RGB), one visible (either direct blit or CB-transformed). `{willReadFrequently: true}` passed to both `getContext` calls for performance.
- **Color blindness** — 3×3 Brettel matrices stored as flat 9-element arrays. Applied via `getImageData` → per-pixel multiply → `putImageData` every frame. CSS filters were tried first but fail silently with `globalCompositeOperation: "lighter"` blending, which is why pixel-level transforms were required.
- **Color math** — pure JS functions for RGB↔HSL, WCAG relative luminance (IEC 61966-2-1 linearization), contrast ratio, harmony generation, and lightness-step auto-adjustment. No color library.
- **Fader drag** — global `mousemove` / `mouseup` listeners attached on mousedown and removed on mouseup to support dragging outside the element bounds without losing the interaction.
- **File authoring note** — shell heredocs were avoided because bash interprets backticks inside them as command substitution, corrupting template literals in JSX. The final file was written using Python string literals to preserve all characters exactly.
- **Google Fonts** — Courier Prime loaded via `<link>` in the document head.
